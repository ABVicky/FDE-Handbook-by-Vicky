# Case Studies

Short stories of FDE engagements: what the client asked for, what the real problem was, what was built, and what went wrong along the way.

## Two kinds of case study

| Label | Meaning |
| --- | --- |
| 🧪 **Illustrative** | A realistic composite written for teaching. Not about a real company. |
| 📰 **Sourced** | Based on a public, citable source (company blog, conference talk, published customer story), with the link and date. |

The first three are illustrative. **We need sourced case studies.** If you know a public write-up of a real deployment, see [CONTRIBUTING.md](../CONTRIBUTING.md).

## How to read each case
1. Read the **situation** and stop. What would you do first?
2. Read the rest and compare.
3. Answer the **discussion questions** in writing.

## Case study template
Situation · What was asked for · What discovery found · What was built · What went wrong · Outcome · Lessons · Discussion questions · Source (sourced cases only).
