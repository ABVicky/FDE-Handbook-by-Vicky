Security policy

The code in this repository is for learning, but people deploy learning code. If you find a security problem (for example in projects/admitflow), please don't open a public issue.

Report it privately through GitHub's "Report a vulnerability" (Security → Advisories) on this repository, or contact the maintainers listed in the README. Include what you found, how to reproduce it, and its impact. We'll acknowledge reports as soon as we can and credit you if you'd like.

If you've deployed AdmitFlow with real data, also read Module 10 and the runbook.
