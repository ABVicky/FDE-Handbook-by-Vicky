Contributing

Thank you for helping build the FDE Handbook by Vicky.

Quality bar for lessons

  • [ ] Starts with why it matters to an FDE, ideally through AdmitFlow
  • [ ] Explains what it is, why it exists, how it works, where it's used, and its limitations
  • [ ] Includes a diagram where it helps (Mermaid preferred, so GitHub renders it)
  • [ ] Code runs as written, with pinned versions
  • [ ] Links to official documentation first
  • [ ] Ends with a "Check yourself" question
  • [ ] Read by at least one person who doesn't already know the topic

Writing style

  • Plain, direct English. Short sentences. Explain jargon the first time you use it.
  • Address the learner as "you."
  • Mark content as Core or Stretch.
  • Label illustrative examples clearly; never present invented stories or numbers as real.
  • Add a Last verified: YYYY-MM-DD line to tool-specific lessons.

Licensing

This handbook's terms of use are in the Copyright & Terms of Use section of the README. Before your contribution is merged, the maintainers will ask you to confirm that you wrote it (or have the right to contribute it) and agree to it being published under those terms.

Code of conduct

Be kind, assume good intent, and help beginners. See CODE_OF_CONDUCT.md.
