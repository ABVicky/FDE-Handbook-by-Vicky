# Module 05 — Resources

## SQL and databases
| Resource | Why |
| --- | --- |
| [PostgreSQL tutorial (official)](https://www.postgresql.org/docs/current/tutorial.html) | Clear introduction from the source |
| [PostgreSQL documentation](https://www.postgresql.org/docs/) | Reference: data types, indexes, `EXPLAIN` |
| [SQLite documentation](https://www.sqlite.org/docs.html) | Including the [query planner overview](https://www.sqlite.org/queryplanner.html) |
| [Use The Index, Luke](https://use-the-index-luke.com/) | The best free guide to indexing and query performance |
| [SQLBolt](https://sqlbolt.com/) / [Select Star SQL](https://selectstarsql.com/) | Interactive SQL practice |
| [Mode SQL tutorial: window functions](https://mode.com/sql-tutorial/sql-window-functions/) | Window functions explained with examples |
