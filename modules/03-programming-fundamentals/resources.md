# Module 03 — Resources

Official documentation first.

## Python
| Resource | Why |
| --- | --- |
| [The Python Tutorial](https://docs.python.org/3/tutorial/) | The official, complete introduction |
| [Python Standard Library](https://docs.python.org/3/library/) | Reference for `csv`, `json`, `pathlib`, `datetime`, `logging`, `argparse`, `unicodedata` |
| [Python Unicode HOWTO](https://docs.python.org/3/howto/unicode.html) | Encodings and normalization, properly explained |
| [Python Packaging User Guide](https://packaging.python.org/en/latest/tutorials/packaging-projects/) | `pyproject.toml` and packaging |
| [venv documentation](https://docs.python.org/3/library/venv.html) | Virtual environments |
| [uv](https://docs.astral.sh/uv/) | *Stretch:* fast modern project and package manager |
| [pytest documentation](https://docs.pytest.org/) | Fixtures, parametrize, and more |
| [mypy documentation](https://mypy.readthedocs.io/) | Type checking |
| [HTTPX](https://www.python-httpx.org/) | HTTP client, including async and mock transports |

## Git and GitHub
| Resource | Why |
| --- | --- |
| [Pro Git (free book)](https://git-scm.com/book/en/v2) | The definitive guide; chapters 1–3 are enough to start |
| [GitHub Docs: pull requests](https://docs.github.com/en/pull-requests) | Opening, reviewing and merging PRs |
| [Learn Git Branching](https://learngitbranching.js.org/) | Interactive, visual practice |

## JavaScript and TypeScript
| Resource | Why |
| --- | --- |
| [MDN JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide) | The standard reference |
| [javascript.info](https://javascript.info/) | Clear, thorough modern tutorial |
| [Node.js: Learn](https://nodejs.org/en/learn) | Running JavaScript outside the browser |
| [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html) | Official introduction |

## Practice and interviews
- LeetCode / HackerRank: start with easy array, string and hash-map problems
- "Falsehoods programmers believe about names" (search the title): essential reading before you validate anyone's name
