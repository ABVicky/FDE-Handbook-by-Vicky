# Exercise 03 — Estimate AdmitFlow's monthly cost

Ms. Chen (finance) needs a monthly cost estimate before approving production. Using your chosen provider's **official pricing calculator**:

1. List every resource AdmitFlow needs (API, database, dashboard hosting, secrets, logs, scheduled job, registry, backups)
2. State your sizing assumptions (users, requests per day, database size, log volume)
3. Give a monthly **range** (low / expected / high), dated, with a link or screenshot of the calculator
4. Name the three biggest risks to the estimate, and how you'd control each
5. Propose budget alerts (amounts, recipients)
6. Write the 100-word summary you'd send Ms. Chen
