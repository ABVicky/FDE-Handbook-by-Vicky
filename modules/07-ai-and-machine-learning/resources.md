# Module 07 — Resources

| Resource | Why |
| --- | --- |
| [scikit-learn user guide](https://scikit-learn.org/stable/user_guide.html) | Pipelines, models, model evaluation, the common pitfalls page |
| [scikit-learn: common pitfalls](https://scikit-learn.org/stable/common_pitfalls.html) | Leakage and inconsistent preprocessing, from the source |
| [pandas: 10 minutes to pandas](https://pandas.pydata.org/docs/user_guide/10min.html) | Data exploration basics |
| [Google: Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) | Free, practical introduction including classification metrics and fairness |
| *Hands-On Machine Learning*, Aurélien Géron (book) | The standard practical ML book |
| [Hugging Face course](https://huggingface.co/learn) | Transformers and embeddings, hands-on |
| [PyTorch: Learn the Basics](https://pytorch.org/tutorials/beginner/basics/intro.html) | *Stretch:* neural networks |
| ["Model Cards for Model Reporting" (Mitchell et al.)](https://arxiv.org/abs/1810.03993) | Where the model-card idea comes from |
| [Google: Rules of Machine Learning](https://developers.google.com/machine-learning/guides/rules-of-ml) | Practical engineering advice, starting with "don't be afraid to launch without ML" |
