# Module 10 — Resources

## Security
| Resource | Why |
| --- | --- |
| [OWASP Top 10](https://owasp.org/www-project-top-ten/) | The standard list of web risks |
| [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/) | Practical guidance: headers, logging, authentication, secrets |
| [OWASP Top 10 for LLM Applications](https://genai.owasp.org/) | AI-specific risks |
| [Threat Modeling Manifesto](https://www.threatmodelingmanifesto.org/) | The four questions behind threat modelling |
| [MDN: Content Security Policy](https://developer.mozilla.org/en-US/docs/Web/HTTP/CSP) | CSP in depth |
| [pip-audit](https://github.com/pypa/pip-audit) · [npm audit](https://docs.npmjs.com/cli/commands/npm-audit) · [Trivy](https://trivy.dev/) | Dependency and image scanning |
