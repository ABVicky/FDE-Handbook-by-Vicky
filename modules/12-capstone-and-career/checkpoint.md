# Module 12 — Readiness check

There's no quiz for this module. Instead, answer these honestly, with links to evidence. If you can't link evidence, that's your next piece of work.

| # | Can you show… | Evidence link |
| --- | --- | --- |
| 1 | a problem statement you wrote from real discovery, that names no solution? | |
| 2 | a deployed system someone else used, and what happened when they did? | |
| 3 | an evaluation with numbers against a baseline, including where it failed? | |
| 4 | a security review and the tests behind its controls? | |
| 5 | an alert that would catch a real failure, and the runbook entry for it? | |
| 6 | a business case with labelled assumptions and a conservative scenario? | |
| 7 | a handover someone else used without asking you? | |
| 8 | a difficult message you wrote to a client: a delay, a failure, or a "no"? | |
| 9 | three mock interviews and what you changed after them? | |
| 10 | your self-assessment at level 3+ on all five capabilities? | |

Eight or more with evidence: start applying. Fewer: pick the gaps and close them, one by one.
