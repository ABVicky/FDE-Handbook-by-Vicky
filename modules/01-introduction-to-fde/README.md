## Outcome

After this module you can explain what a Forward Deployed Engineer does, tell the role apart from similar jobs, read an FDE job description critically, and run your first discovery conversation with a real person.

## Why this matters to an FDE

Imagine you join an educational institute as their engineer. On day one, the director says: *"We need an AI chatbot."* A developer starts building one. An FDE asks questions first and finds that the real problem is this: 40% of enquiries never get a follow-up call because leads are scattered across five spreadsheets and two inboxes. A chatbot would not have fixed that.

That gap, between what a customer *asks for* and what will actually *change their outcome*, is where FDEs work. Before you learn any technology, you need a clear picture of the job, because it shapes how you'll learn everything that follows: always tied to a real problem, a real user and a measurable result.

This module is short on code and long on thinking. Don't skip it, even if you're already an engineer.
