# Exercise 03 — Compare five job descriptions

**Goal:** see for yourself what the market asks for, and which kind of FDE role suits you.

## Steps

1. Find **five** current FDE (or closely related) job postings from **at least three different types** of employer: e.g. an AI lab, a data platform, a startup, a consultancy.
2. Save each one as a dated snapshot in `resources/job-descriptions/YYYY-MM-company-title.md` (paste the text; include the URL and the date you saved it).
3. Fill in this table:

| Company | Type | Eng ↔ Consult (1–5) | Languages | Cloud | AI skills | Data skills | Integration skills | Client skills | Travel | Interview hints |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | | | | |

4. Answer below the table:
   - Which **three skills** appear in four or five postings? (These are your core.)
   - Which skill appeared only once? (Probably learned on the job.)
   - Which posting fits you best today, and what's your biggest gap for it?
   - Which posting do you want to be ready for in 12 months?

## Done when
- [ ] Five snapshots saved with dates and URLs
- [ ] Table complete
- [ ] Four questions answered

> **Contributing back:** if your snapshots are from public postings, consider opening a pull request to add them to `resources/job-descriptions/`. They help keep the curriculum current.
