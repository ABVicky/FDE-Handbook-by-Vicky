# Module 02 — Resources

Official and long-standing references first. Note the date you read each one.

## Command line
| Resource | Why |
| --- | --- |
| [The Missing Semester of Your CS Education (MIT)](https://missing.csail.mit.edu/) | Excellent free lectures on the shell, scripting, and tools |
| [GNU Bash manual](https://www.gnu.org/software/bash/manual/) | The definitive reference |
| [explainshell.com](https://explainshell.com/) | Paste a command and see what each part does |
| `man <command>` | Already on your machine |

## Operating systems and Linux
| Resource | Why |
| --- | --- |
| [Ubuntu: The Linux command line for beginners](https://ubuntu.com/tutorials/command-line-for-beginners) | Gentle, official tutorial |
| [Microsoft: Install WSL](https://learn.microsoft.com/en-us/windows/wsl/install) | Official WSL setup |

## Networking and HTTP
| Resource | Why |
| --- | --- |
| [MDN: An overview of HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview) | Clear, authoritative introduction |
| [MDN: HTTP response status codes](https://developer.mozilla.org/en-US/docs/Web/HTTP/Status) | Reference for every status code |
| [MDN: How does the Internet work?](https://developer.mozilla.org/en-US/docs/Learn_web_development/Howto/Web_mechanics/How_does_the_Internet_work) | Big picture in plain language |
| [Cloudflare Learning Center: What is DNS?](https://www.cloudflare.com/learning/dns/what-is-dns/) | Good explanations of DNS, TLS and networking basics |
| [curl documentation](https://curl.se/docs/) | Everything curl can do |

## Stretch
- "Julia Evans zines" (search the name): short, friendly explanations of networking, DNS, and Linux internals.
- *How Linux Works* by Brian Ward (book): deeper OS understanding.
