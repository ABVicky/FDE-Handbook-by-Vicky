# Exercise 04 — Integration map and security review

Using the [security review template](../../../templates/security-review.md), write AdmitFlow's security and privacy review as of this module:

1. The integration map (Lesson 01), with system of record per data type
2. Data inventory and data flows, including **every third party** (LLM provider, CRM, email, WhatsApp, Google sign-in, hosting)
3. Identity and access: human roles, SSO, provisioning and leavers, every service credential
4. AI-specific controls: grounding, citations, approval gates, MCP scope
5. At least five known gaps, each with a mitigation and a date

Keep it under four pages. A reviewer should be able to read it in 15 minutes.
