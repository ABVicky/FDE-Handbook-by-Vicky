# Interview preparation

FDE interviews usually combine several of these. Read job descriptions (Module 01, Lesson 06) to see which a company emphasizes.

| Interview | What's assessed | Prepare with |
| --- | --- | --- |
| **Coding** | Clean, correct code under time pressure; data structures; talking through trade-offs | [coding.md](coding.md) + [runnable solutions](solutions/coding_solutions.py) |
| **System design** | Architecture for a realistic, messy client problem | [system-design.md](system-design.md) |
| **Debugging / unfamiliar code** | Finding a bug in code you've never seen | [debugging.md](debugging.md) |
| **Client scenario / case** | Discovery, communication, judgement under ambiguity | [client-scenarios.md](client-scenarios.md) |
| **Take-home project** | Building something small, end to end, with docs and tests | Your capstone habits; see [take-home.md](take-home.md) |
| **Behavioural** | Ownership, conflict, learning from failure | [behavioural.md](behavioural.md) |

Practise **out loud**, with a timer, with someone who interrupts with questions. Most candidates who fail FDE interviews fail on communication, not code.
