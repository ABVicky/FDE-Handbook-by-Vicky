# The Field Track

Every module has a client-facing exercise. Together they build C1 (understand the business) and C5 (lead the engagement), the skills that make an engineer an FDE.

| Module | Exercise | Skill |
| --- | --- | --- |
| 01 | [Your first real discovery interview](../modules/01-introduction-to-fde/field-track.md) | Discovery, problem statements |
| 02 | [Explain it to a non-technical person](../modules/02-computing-foundations/field-track.md) | Plain-language explanation |
| 03 | [Weekly status updates](../modules/03-programming-fundamentals/field-track.md) | Written updates, risks, asks |
| 04 | [Scope and estimate before you build](../modules/04-software-engineering/field-track.md) | Scoping, estimation, assumptions |
| 05 | [Ask for data access the right way](../modules/05-databases-and-data-engineering/field-track.md) | Data minimization, trust with IT |
| 06 | [Deploying into a restricted client environment](../modules/06-cloud-and-infrastructure/field-track.md) | Planning around constraints and reviews |
| 07 | [Tell the director the truth about the model](../modules/07-ai-and-machine-learning/field-track.md) | Delivering unwelcome findings |
| 08 | [Demo the assistant, including where it fails](../modules/08-generative-ai-engineering/field-track.md) | Demos, acceptance criteria |
| 09 | [The security questionnaire](../modules/09-enterprise-integration/field-track.md) | Security reviews |
| 10 | [Game day](../modules/10-production-security-reliability/field-track.md) | Incident response and communication |
| 11 | [A real engagement, in miniature](../modules/11-business-and-client-engineering/field-track.md) | End-to-end engagement |
| 12 | [Mock interviews](../modules/12-capstone-and-career/field-track.md) | Interviews, including client scenarios |

Supporting material: [discovery question bank](../templates/discovery-question-bank.md), [stakeholder map](../templates/stakeholder-map.md), [client-scenario scripts](../interview-prep/client-scenarios.md).
