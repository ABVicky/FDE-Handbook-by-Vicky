# 🌟 About the FDE Handbook by Vicky

### The complete, practical open-source curriculum for becoming a production Forward Deployed Engineer (FDE).

---

## 1. What Makes This Handbook Special

We built this learning environment to be fast, distraction-free, 100% offline-ready, and respectful of your privacy:

- 🏗️ **One Running Production Project:** You build *AdmitFlow*, an enterprise AI admissions system for an educational institution (Northbridge Institute of Professional Studies), incrementally from discovery to deployment.
- 🎯 **Competency Radar & Self-Assessment:** Visual radar spider chart and capability scorecards across the 5 core FDE disciplines (C1: Business, C2: Software, C3: AI & Data, C4: Deploy & Integrate, C5: Client Leadership).
- ⚡ **Interactive Architecture Flow:** Real-time data pipeline visualizer showing lead ingestion, deduplication, SQLite/PostgreSQL storage, RAG retrieval, and LLM scoring.
- 🔎 **Instant Fuzzy Search:** Press **⌘K** or **/** anywhere in the platform to instantly search across 239 handbook lessons, code files, datasets, and guides.
- 🌗 **High-Contrast Cinematic Theme:** Custom light and dark themes using a focused Crimson (`#A31C18` / `#E53935`), Emerald (`#218354` / `#39A875`), and Charcoal palette tested for WCAG AAA readability.
- 📱 **100% Offline & Private:** Zero third-party trackers, zero cookies, zero external framework runtime bloat. All checklist states and assessment scores persist locally in your browser storage.
- ⌨️ **Keyboard-First Navigation:** Use **⌘K** to search, **Esc** to dismiss modals, and seamless navigation across all 12 modules.
